## Quick Revision Tips

1. **Read the approach comment first** - understand the key insight before looking at code
2. **Focus on patterns** - many problems share the same underlying technique
3. **Know your complexities** - be ready to explain time/space trade-offs
4. **Edge cases** - empty input, single element, negative numbers, overflow
