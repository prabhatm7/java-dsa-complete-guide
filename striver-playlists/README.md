# Striver (Take U Forward) Playlists — Java Solutions

Java implementations of problems from Striver's DSA playlists.

## Format
Each file has a header block only — no inline comments:
- Problem statement (1 line)
- Intuition (1-2 lines)
- Time complexity
- Space complexity

## Notes
- A2Z DSA Sheet playlist intentionally skipped.
- BST topics (insert/search/delete/floor/ceil/inorder successor, etc.) are covered in `02-sde-sheet/21-bst-1/` and `22-bst-2/` rather than a standalone folder.
- Some files use `b/c` suffixes (e.g., `40b-`, `12b-`) to slot into existing numbering without renumbering the rest of the playlist.
